# «Шальные Шнурки» — AI-консультант

Веб-приложение для консультации клиентов. Агент генерирует ответы через OpenAI-совместимый API, использует базу знаний компании, поддерживает контекст текущего диалога, сохраняет предпочтения и историю между перезапусками и разделяет права клиента и администратора. Локально используется SQLite, а на Vercel — совместимая облачная база Turso.

## Запуск

Требуется Node.js 22.5 или новее. В каталоге проекта можно запустить готовый PowerShell-скрипт (он также найдёт Node.js из среды Codex):

```powershell
.\start.ps1
```

При установленном `npm` альтернативная команда — `npm start`.

Для генерации LLM добавьте в локальный `.env`:

```dotenv
PROXY_API_API_KEY=ваш_ключ
PROXY_API_OPENAI_BASE_URL=https://адрес-прокси/v1
PROXY_API_OPENAI_MODEL=openai/gpt-4.1-mini
```

Модель можно заменить на другую, доступную у прокси. Если параметры отсутствуют или OpenAI-совместимый сервис временно недоступен, приложение автоматически использует локальный резервный генератор и продолжает работать.

Откройте <http://127.0.0.1:3000>. При первом запуске автоматически создаётся администратор:

- логин: `admin`
- пароль: `admin123`

Демонстрационные клиенты с разными предпочтениями:

- `lace_anna` / `client123`
- `lace_ivan` / `client123`

Для реального использования эти демонстрационные реквизиты следует заменить.

## Проверка

```powershell
.\test.ps1
```

Тесты проверяют текущий диалог, сохранение памяти после перезапуска, влияние прямого изменения SQL-данных на ответ, запрет доступа к чужому профилю и корректное формирование запроса к LLM.

## Vercel

Проект содержит готовую serverless-функцию `api/[...route].js`, конфигурацию `vercel.json`, stateless-авторизацию и адаптер Turso. Полный порядок действий приведён в `docs/РАЗВЕРТЫВАНИЕ_НА_VERCEL.md`.

## Данные

Данные хранятся локально в `data/laces.sqlite`. Пароли не записываются открытым текстом: используется `scrypt` с индивидуальной солью. Файл рабочей базы исключён из Git.

Полная SQL-схема находится в `database/schema.sql`. Русскоязычные материалы:

- `docs/ОПИСАНИЕ_SQL_БАЗЫ.md` — таблицы, связи, память и права доступа;
- `docs/РЕЗУЛЬТАТЫ_ТЕСТИРОВАНИЯ.md` — ход и результаты проверочных сценариев.
- `docs/РАЗВЕРТЫВАНИЕ_НА_VERCEL.md` — пошаговое развёртывание и переменные окружения.
- `knowledge/company.txt` — база знаний, передаваемая модели как справочный контекст.
