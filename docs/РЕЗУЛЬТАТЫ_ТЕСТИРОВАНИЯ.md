# Результаты тестирования проекта «Шальные Шнурки»

Дата проверки: 3 ноября 2026 года.

Команда запуска:

```powershell
.\test.ps1
```

Среда: Node.js 24.19.0, SQLite 3.53.3.

## Сценарий 1. Память текущего диалога

1. Создан клиент.
2. В первом сообщении указан тип обуви и бюджет 4000 рублей.
3. Во втором сообщении указан только цвет.
4. Агент использовал ранее названный бюджет, а в таблице `messages` появились четыре связанные записи: два сообщения клиента и два ответа агента.

Результат: **пройдено**.

## Сценарий 2. Долгосрочная память между диалогами

1. Клиент сообщил имя Борис, красный цвет и стиль «киберпанк».
2. Создан новый диалог.
3. Сервер и подключение к SQLite полностью остановлены.
4. Приложение заново запущено с тем же файлом базы.
5. Ранее выданный подписанный токен принят новым экземпляром сервера.
6. В новом диалоге агент вспомнил имя и стиль.

Результат: **пройдено**.

## Сценарий 3. Изменение данных в базе влияет на ответ

1. Клиент сообщил, что ищет классические шнурки для ботинок.
2. Прямым SQL-запросом в `user_facts` установлен цвет `золотой`.
3. В следующем запросе агент предложил золотой вариант.

Результат: **пройдено**.

## Сценарий 4. Защита чужих данных

1. Выполнен вход под демонстрационным клиентом `lace_anna`.
2. Клиент попытался прочитать список пользователей.
3. Клиент попытался изменить и удалить сведения пользователя `lace_ivan`.
4. Все три запроса получили HTTP `403`, данные Ивана остались неизменными.

Результат: **пройдено**.

- `lace_ivan`: Иван, чёрные спортивные кевларовые шнурки для ботинок.

Результат: **пройдено**.
